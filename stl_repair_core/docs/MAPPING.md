# Mapping: Sutura 0.9.8 to stl_repair_core

Pinned source: `Krateian/Sutura` @ `158d9ab688fd43098cdd7fe8ad58f8f0049c34f9` (tag 0.9.8).
No Sutura file was copied verbatim. Every module below is a re-implementation of the
cited functions, written against the same contract and then tightened where the
structural-mechanics use case needs it. Every behavioural difference is listed and is
covered by a test or by the corpus benchmark.

## Behavioural differences on identical inputs (summary)

1. **Holes:** Sutura closes every loop up to 1000 edges, whatever its size, so intentional openings are closed. Here only loops with diameter ≤ `max_hole_diameter` are closed.
2. **Small components:** Sutura deletes every component under 8 faces by default, which deletes a tetrahedron or a small pin. Here components are removed only under an explicit area threshold, and never when healthy.
3. **Non-manifold edges:** Sutura deletes faces, which can open holes. Here only fin faces are removed, inside the deviation tolerance. Shared-edge solids are reported and the mesh FAILs.
4. **Pinched vertices:** Sutura duplicates the vertex in memory (`test_pinched_vertices.py`). An STL has no connectivity, so the split disappears when the file is reloaded. Here the vertex is reported and the status is FAIL.
5. **Coordinates:** Sutura works in float32. Here everything is float64; binary STL values are float32-exact, so binary output is bit-identical for kept vertices.
6. **Order dependence:** Sutura's duplicate removal keeps the last copy, and its orientation BFS starts at face 0. Here every step runs on the canonical order (`test_permutation.py`).
7. **Stage 2, Tamponade/Stent, Coaptation, Dressing/Splint/Graft, fTetWild/CDT, extreme passes, SI excise + re-cap:** none of these is extracted (scope exclusions).
8. **Self-intersection count:** Sutura's `sutura_geom.si_faces_exact` flags fewer faces than this package on 19 of 40 corpus meshes. It never flags more. The `thingi10k_1356633` case was checked by hand in exact rational arithmetic (`fractions.Fraction`). Face 3321 is crossed by faces 4006, 4171 and 4172. For 4172, both points where its edges cross the plane lie strictly inside 3321, so the crossing is proper. Sutura reports 0 even when given the isolated pair. PyMeshLab (VCG) flags 3 faces there. Across the corpus, this package and PyMeshLab agree on zero versus non-zero on 38 of 40 meshes. The two disagreements, `100827` and `502009`, are coplanar or touching contacts that VCG counts and this package classes as non-proper. Data: `benchmarks/si_crosscheck.json`.
